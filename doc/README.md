## ドキュメント作成方針

本プロジェクトでは、実装方法だけでなく、

- なぜその処理を行うのか
- どのようなアルゴリズムを使用しているのか
- 入力から出力までデータがどのように流れるのか
- 各パラメータや設定値にどのような意味があるのか

を説明できる状態にすることを目的としてドキュメントを作成します。

特にEEG信号処理については、実装コードと数式・理論を対応させながら整理します。
