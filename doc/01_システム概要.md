# システム概要

## 1. システム名と目的

**EEG Analysis Platform** は、CSV形式のEEGデータをWebブラウザから読み込み、波形確認、前処理、周波数解析、欠損検出・再構築および再構築精度評価を行う研究・デモ用プロトタイプである。

現状は次の一連の操作に対応する。

```text
CSV入力
  → 波形・欠損情報の確認
  → 線形補間またはMLPによる再構築
  → Filter
  → PSD / Band Power
  → 再構築精度の比較
```

## 3. 入力CSV

`time` 列を必須とし、それ以外の列をEEGチャンネルとして扱う。

```csv
time,Fp1,Fp2,C3,C4
0.000,1.2,0.8,-0.4,0.1
0.004,1.1,,-0.3,0.2
0.008,1.3,0.9,-0.5,0.0
```

- `time` は数値かつ単調増加であること。
- 2サンプル以上、1チャンネル以上を必要とする。
- EEG値は数値または欠損値（NaN）を許可する。
- サンプリング周波数は `1 / median(diff(time))` で推定する。
- 記録時間は `last time - first time` で算出する。
- BackendからFrontendへ返す配列の向きは `[channel][sample]` である。

## 5. データの扱い

- アップロードデータと解析結果はFrontendのStateに保持する。
- DB・Blob Storageなどへの永続化は行わない。
- 新しいCSVをアップロードすると、以前の再構築・Filter結果を破棄する。
- Originalデータは上書きせず、再構築結果とFilter結果を別に保持する。
- 欠損を含むデータへFilterを適用する場合は、先に再構築を行う。

## 6. 現在の制約

- CSVのみ対応し、EDF/BDFは未対応。
- ユーザー認証・権限管理は未実装。
- AI再構築は各チャンネルを独立に学習し、チャンネル間相関を利用しない。
- MLPはアップロードされたデータごとに学習するため、長いデータでは処理時間が増える。
- リアルタイム解析とEEG分類は未実装。
- 医療診断や臨床判断を目的としたシステムではない。
