# EEG Analysis Prototype

## 実行手順

### 1. リポジトリをクローン

```bash
git clone <repository-url>
cd <repository-name>
```

### 2. Dockerコンテナを起動

```bash
docker compose up --build
```

### 3. ブラウザでアクセス

```text
http://localhost:5173
```

## 終了

```bash
docker compose down
```

## 再起動

```bash
docker compose up
```
